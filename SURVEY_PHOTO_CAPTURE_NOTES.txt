NorthGroup One - Survey Photo Capture

Location in app:
Dashboard > Quick Actions > Field Tools > Survey Photo Capture

Implemented:
- Create/select local project and Start Photo ID
- Select a surveyor and prefix new filenames with their initials
- Gallery date folders for faster daily review
- Export the whole project or selected capture dates with matching JSON/CSV
- Automatic next Photo ID only after a successful complete save
- Optional Point ID and comment
- Standard image types plus custom type
- Large camera-first capture screen with GPS, Photo ID and Point ID overlays
- Image Type selector moved onto the camera preview
- Every shutter press now opens a required full-screen Image Type step before
  the official JPEG, filename and register entry are created
- Retake discards the temporary preview without using or incrementing Photo ID
- Project Details moved beneath capture controls to reduce top-screen clutter
- Rear-camera JPEG capture with flash OFF by default and an ON/OFF control
- Live GPS accuracy with green/amber/red status and poor/reduced GPS warnings
- Controlled Project/ImageType/filename storage and duplicate _01, _02 suffixes
- GPS EXIF merge while preserving existing camera EXIF where available
- Project.json source record and rebuildable Photo_Register.csv
- Internal project gallery, full-screen photo review/zoom and photo deletion
- Clear required-location prompt with direct iPhone Settings shortcut
- Visible Done controls and drag-to-dismiss keyboard behaviour
- Project QA summary
- Optional convenience copy to iPhone Photos (OFF by default)
- ZIP export using the iOS share sheet
- iOS file sharing enabled for Apple Devices > Files

Important testing note:
Camera, real GPS, iOS Files sharing and Photos permissions must be tested on an
iPhone. Expo Go can exercise most of the workflow. The Apple Devices > Files
feature is applied to a development/production iOS build through app.json.

Also added:
- SE-14 Export Completed PDF now immediately shows "Preparing PDF..." until
  PDF preparation finishes and the iOS share sheet opens.

TMR Feature Guide assets:
- Updated supplied TMR asset library merged as the authoritative image set.
- 98 images registered across 28 populated feature-code folders.

Navigation and branding:
- New Field Tools page contains Survey Photo Capture and TMR Feature Guide
- TMR Feature Guide removed from the Forms page
- Forms and Field Tools retain the moving topo background and tappable spinning
  logo, with centred NORTHGROUP / FORMS and NORTHGROUP / FIELD TOOLS titles
- Field Tools now uses the same dark navy banner and compact white-card layout
  as Forms; long tool descriptions were removed so both options fit on screen
- Back and Dashboard labels now reflect the actual navigation destination, and
  the Forms page includes a visible Dashboard control
- Active Capture view uses a compact Projects back control so the camera fills
  most of the screen

New operational forms:
- S-501 Light Vehicle Pre-Start Checklist with all 21 source inspection items,
  OK defaults, editable Damaged/Missing states, fault remarks, drafts and a
  polished two-page PDF export
- S-506 Journey Management Plan with all journey fields, Yes defaults for the
  Yes/No/N/A review, local drafts and a polished one-page PDF export
- S-506 includes concise Journey Guidance based on S-09: the 150 km trigger,
  buddy contact, charging/contact response, pre-start and return-trip reminders
- Both forms use the same animated form-menu and Fill Form flow as S-500/SE-14
